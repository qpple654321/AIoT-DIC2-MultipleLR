METHODOLOGY

Feature Selection Methods

Lasso

L1 regularization ranking → top-k predictors → OLS refit.

Forward SFS

Sequentially adds the predictor that improves the model most.

RFE

Recursive feature elimination removes the weakest predictors.

ElasticNet

L1 + L2 regularization ranking → top-k → OLS refit.

Exhaustive

Evaluates candidate subsets and selects the best-performing combination.

Experiment Flow

  1. Business Understanding — predict startup profit / housing value.
  2. Data Understanding — inspect predictors, target and categorical variables.
  3. Data Preparation — encode categories and split data.
  4. Modeling — five feature-selection schemes with k=1…5, then OLS.
  5. Evaluation — RMSE, MAE, R², coefficient diagnostics and residuals.
  6. Deployment — GitHub Pages interactive explorer.
